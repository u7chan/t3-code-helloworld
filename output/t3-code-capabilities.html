The open-source control surface for coding agents

エージェントを、
ひとつの作業画面に。

T3 Codeは、CodexやClaude Codeなどのコーディングエージェントをまとめ、PCでもスマートフォンでも作業を続けられるオープンソースのコントロール画面です。

6つのエージェントに対応 Web・Desktop・Mobile MIT License 公式情報を確認：2026年10月3日
ひとことで

使い慣れたコーディングエージェントを自分の環境で動かし、会話・作業スレッド・差分確認・GitHubなどへのPR作成をひとつの場所から進められます。利用するモデルや契約は、接続したプロバイダーのものを使います。

Before you start

デスクトップアプリは不要。CLIとログインを用意

T3 Codeからエージェントを起動するため、プロジェクトを動かすマシンに各エージェントの実行環境と認証を設定します。

エージェント用意するもの認証
OpenAI CodexCodex CLIcodex login
Claude CodeClaude Code CLIclaude auth login
Google AntigravityT3 Code設定からランタイムを準備設定画面からGoogleでサインイン
つまり：CodexやClaudeのデスクトップGUIアプリは必要ありません。CLIとそのアカウント認証を、エージェントを動かす環境に用意します。スマートフォンから使う場合も、CLIを入れるのは接続先のマシンです。
02 / One workspace

依頼からレビューまでをつなぐ

タスクをスレッドに分けて整理し、必要なら独立したブランチと作業フォルダー（worktree）で進められます。

1

タスクをスレッドに

会話と作業単位を分けて、別の仕事を整理する。

2

進め方を選ぶ

必要に応じてworktreeを使い、作業場所を分ける。

3

変更を確かめる

生成されたコードの差分を確認し、レビューする。

4

Gitで共有する

コミット・pushして、対応するGitホストでPRを作成する。

03 / Source control

Git連携を作業画面に

リポジトリの取得から変更レビュー、Pull Requestまで。連携できる機能はホストによって異なります。

領域できること状態
リポジトリ対応ホストからclone・publish✓ 対応
レビュー変更・コメントの確認、PR/MRの作成✓ 対応
対応ホストGitHub、GitLab、Forgejo、Gitea、Bitbucket、Azure DevOps✓ 対応
一部操作スタックPRや自動マージなど、ホスト・権限ごとに差がある△ 条件あり
04 / Permission modes

エージェントの権限を選ぶ

スレッドごとに、コマンドやファイル変更をどのように許可するか調整できます。

Supervisedコマンドやファイル変更の前に確認
Auto-accept edits編集を自動許可。ほかは確認する場合あり
Auto通常の操作を自動レビューし、必要時に確認
Full access確認を挟まずコマンド・編集を許可
プロバイダーによる違い：権限モードの対応範囲や承認の動きは、接続先エージェントによって異なります。
05 / Multi-surface

作業場所を選ばない

DesktopWindows・macOS・Linux向けアプリ

MobileiOS・Androidアプリから遠隔操作

手元の端末から別のマシンへ

T3 Codeを動かすマシンに接続し、その環境のプロジェクトとエージェントを操作します。

T3 Connectルーターのポート転送を設定せず接続
LAN / Tailscale同じネットワークやプライベートネットワーク経由
SSHデスクトップアプリからリモート環境へ
Web / Mobile接続先のサーバーを別端末から利用

リモート作業中は、ホストのマシンが起動し、ネットワークから到達できる必要があります。

自分の道具で始めて、必要なら自分流に

T3 Codeはオープンソース。プロバイダーの認証・契約を使い、コードをforkして調整したり、自分の環境で動かしたりできます。

06 / Get started

使い始める3ステップ

まずはひとつのプロバイダーを接続。アカウント認証や利用条件は、そのプロバイダーの設定に従います。

1

エージェントを準備

対応CLIをインストールしてログイン。AntigravityはT3 Code内からGoogleでサインインできます。

2

T3 Codeを起動

インストールして起動。インストール前のお試し起動にも対応しています。

npx t3@latest
3

プロジェクトで依頼

プロジェクトを選び、新しいスレッドで依頼。権限モードを確認して作業を進めます。
